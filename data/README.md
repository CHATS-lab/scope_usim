# Data

This directory holds the task data the launchers read. Nothing here is
generated by training; run outputs go to `OUTPUT_DIR`.

## `p4g/`: Persuasion for Good

Source: the Persuasion for Good corpus of Wang et al. (2019), "Persuasion for
Good: Towards a Personalized Persuasive Dialogue System for Social Good"
(ACL 2019), as converted to ConvoKit format by the ConvoKit developers
(<https://convokit.cornell.edu/documentation/persuasionforgood.html>).
License: Apache License 2.0, for both the original dataset
(<https://gitlab.com/ucdavisnlp/persuasionforgood>) and the ConvoKit release.

The corpus identifies speakers by their anonymized Amazon Mechanical Turk
worker IDs and carries the self-reported survey answers that the original
authors released (demographics, Big-Five traits, moral foundations, Schwartz
values, decision style). We ship it unchanged.

| Path | Contents | Read by |
| --- | --- | --- |
| `corpus/` | The full ConvoKit corpus in ConvoKit's version-1 on-disk format: `users.json` (1,285 speakers and their survey metadata), `conversations.json` (1,017 dialogues with donation amounts), `utterances.jsonl` (20,932 utterances), `index.json`, `corpus.json`. | `usim/p4g/persona.py` (`convokit.Corpus`, via `--p4g-corpus-path`), `human_study/scripts/seed_p4g_tasks.py` |
| `train/` | 739 dialogues, one `<conversation_id>.jsonl` file each, one utterance per line (`conversation_id`, `utterance_id`, `speaker`, `role`: 0 = persuader, 1 = persuadee, `text`). | `usim/p4g/data_source.py` (`--p4g-dataset-dir`, default `data/p4g/train`) |
| `test/` | 200 dialogues in the same format. No conversation appears in both splits. | `cmd/slime/.../eval_perplexity.py` only (see note below) |

The rollout code reads only the two speaker IDs and the utterance count from
each dialogue file. The persuadee persona prompt is built from that speaker's
metadata in `corpus/users.json`; the recorded dialogue text is not replayed.

How the split was made: the 939 dialogue files were exported from the ConvoKit
corpus in the authors' earlier P4G simulation code and divided into 739
training and 200 test dialogues there. That code is not public and no split
script survives in this repository's history, so the file lists in `train/` and
`test/` are the definition of the split. 78 corpus dialogues are in neither
split. You could fetch the same corpus with
`convokit.download("persuasionforgood-corpus")`; we vendor it because current
ConvoKit releases write a newer on-disk layout (`speakers.json` instead of
`users.json`) and because training containers may not have network access.

Note: the P4G evaluation in `usim/p4g/rollout.py` draws its episodes from the
training data source (`data/p4g/train`); the `usim://p4g/test` paths in
`eval_configs/p4g_6model.yaml` are not read. See the top-level README.

## `cooperbench/`: CooperBench task splits

Task and feature descriptions come from the CooperBench dataset
(<https://github.com/cooperbench/CooperBench>, MIT License); the repository
pins a fork of it at `external/CooperBench`.

| File | Entries | Contents | Read by |
| --- | --- | --- | --- |
| `train_baseline.json` | 170 | one feature per entry (`id`, `repo`, `task_id`, `feature_id`, `description`) | `usim/cooperbench/data_source.py` for `--cooperbench-setting baseline`; `scripts/test_cooperbench_single.py` |
| `train_pairs.json` | 587 | two features per entry (`feature_ids`, `descriptions`) | `usim/cooperbench/data_source.py` for `solo` and `coop` |
| `test_baseline.json` | 29 | held-out single features, disjoint from the training file | not read by code in this repository |
| `test_pairs.json` | 65 | held-out feature pairs, disjoint from the training file | not read by code in this repository |

The two `test_*.json` files are kept as the held-out half of the split; the
CooperBench evaluation harness itself is not part of this repository.
